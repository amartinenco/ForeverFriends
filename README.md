# ForeverFriends
World of Warcraft addon that remembers friend characters and alts you've encountered.

Whenever a friend logs in with a character you have not seen before, the addon records that character name. Over time it builds a history of known characters for each friend, making it easier to mail items, contact friends, or identify alts when they are offline

## Goals

- Track character names seen on the friends list
- Build an alt history automatically
- Store data between play sessions
- Provide slash commands to view known characters
- Keep the addon lightweight and simple
